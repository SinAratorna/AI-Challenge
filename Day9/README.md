# Day 9: Управление контекстом (Сжатие истории)

В этом проекте агент решает проблему бесконечного роста стоимости токенов при долгом диалоге. Вместо того, чтобы отправлять всю историю в API, он использует **архивирование (Compression)**.

## Механика работы Агента (CompressionAgent)
1. **Лимит сообщений:** Агент хранит максимум 4 последних "живых" сообщения (2 от пользователя, 2 от агента). Этого хватает для понимания текущего контекста разговора.
2. **Триггер сжатия:** Как только вы отправляете 5-е сообщение, агент берет 2 самых старых сообщения из истории и отправляет их в LLM (под капотом) со специальным промптом: *"Сгенерируй новое, очень сжатое summary всего разговора в одном абзаце, объединив старое summary и новые детали"*.
3. **Обновление памяти:** Старые сообщения удаляются, а полученный сжатый абзац (Summary) вшивается в начало Системного Промпта. 
Таким образом, агент "помнит" главные факты из прошлого, но тратит на это в 10 раз меньше токенов.

## Особенности интерфейса
- **Мозг агента (Правая панель):** Вы можете наблюдать в реальном времени, как растет "Архив Памяти". Как только происходит сжатие, появляется визуальное уведомление ✨.
- **Тумблер "Включить Сжатие":** Вы можете отключить его прямо во время работы. Если отключить, сообщения будут копиться бесконечно, и цифра "Токены контекста" устремится в космос. Если включить обратно — рост остановится, так как старые сообщения уйдут в архив.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000` в браузере.
