# Day 5: Битва Интеллектов (Версии моделей)

В этом проекте мы тестируем один и тот же запрос на трех разных моделях: от самой слабой (но быстрой) до самой сильной (но дорогой).

## Что реализовано:
Выбрано 3 модели из списка доступных в a101.ru OpenRouter (в файле `app.py`):
1. **Слабая/Быстрая:** `openrouter/google/gemini-3.5-flash`
2. **Средняя/Баланс:** `openrouter/claude-sonnet-5` (или аналогичная среднего уровня)
3. **Сильная/Дорогая:** `openai/gpt-5.6-luna`

По нажатию кнопки запрос уходит параллельно во все три модели. Сервер (на Flask) замеряет и выводит в интерфейс:
- **Время ответа (в секундах)** - чтобы показать, насколько сильная модель медленнее.
- **Количество токенов** - сколько слов сгенерировала модель.
- **Стоимость ($)** - примерная расчетная стоимость этого запроса на основе цены за 1000 токенов (цены захардкожены примерно для демонстрации разницы).

Также внизу страницы представлены аналитические выводы, как и требует задание.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000`
