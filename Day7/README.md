# Day 7: Сохранение контекста (Память Агента)

В этом проекте агент научился запоминать переписку между сессиями (сохранение контекста).

## Как это работает:
Логика инкапсулирована в классе `MemoryAgent` (`agent.py`).
1. **Загрузка памяти:** При инициализации (запуске сервера) агент ищет файл `history.json` на диске и загружает из него список сообщений `[{"role": "user", "content": "..."}, {"role": "assistant", ...}]`.
2. **Процессинг с контекстом:** Когда вы отправляете новое сообщение, агент добавляет его в свой массив, приклеивает системный промпт в самое начало и отправляет **весь массив** в LLM.
3. **Сохранение:** Получив ответ от LLM, агент добавляет его в массив и сразу перезаписывает файл `history.json`.

Даже если вы выключите скрипт `python app.py`, закроете терминал и запустите всё заново на следующий день, агент загрузит `history.json` и продолжит диалог так, будто ничего не произошло.

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000` в браузере.
