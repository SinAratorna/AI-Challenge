# Day 2: Формат ответа (Контроль генерации)

Этот проект демонстрирует разницу между свободным запросом к LLM (без ограничений) и жестко контролируемым запросом. 

## Что реализовано:
Простое Web-приложение на Flask (Python) с киберпанк-интерфейсом.
Оно позволяет отправлять один и тот же базовый запрос (Prompt), но параллельно применяет к нему два разных набора настроек.

1. **Без ограничений:** Обычный prompt, стандартная температура, большой лимит токенов.
2. **С ограничениями:** 
   * **Явное описание формата:** К промпту добавляется системная инструкция о том, в каком виде должен быть ответ (например, JSON, YAML, строгий список).
   * **Temperature:** Настраиваемый параметр (обычно для строгих форматов ставится ближе к 0).
   * **Max Tokens:** Жесткое ограничение длины ответа.
   * **Stop Sequence:** Условие досрочного завершения генерации (например, остановиться, как только будет сгенерирован символ `}` или слово `КОНЕЦ`).

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте браузер по адресу `http://localhost:5000`

*Примечание: По умолчанию приложение пытается взять API ключ из `~/.secrets/ai-private` (основываясь на `opencode.jsonc`), но если его там нет, поле ввода ключа в интерфейсе останется пустым, и вы сможете вставить свой Gemini API ключ вручную перед выполнением запроса.*
