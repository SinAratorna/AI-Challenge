# Day 4: Температура (Temperature)

Этот проект ("Тепловизор ИИ") наглядно демонстрирует, как параметр `temperature` влияет на ответы языковой модели.

## Что реализовано:
Одно простое Web-приложение, которое берет ОДИН ваш запрос (Prompt) и параллельно отправляет его в API три раза, меняя только один параметр — температуру:

1. **T = 0.0 (Абсолютный ноль)** — Детерминированный ответ. Модель выбирает только самые вероятные токены.
2. **T = 0.7 (Баланс)** — Стандартное значение для большинства чат-ботов. Разумный баланс между логикой и креативом.
3. **T = 1.2 (Хаос)** — Высокая креативность. Модель использует редкие слова, иногда жертвуя логикой или форматированием.

Также прямо в интерфейсе (в нижней части) выведены аналитические выводы по каждому параметру, как того требует задание:
- Сравнение точности, креативности и разнообразия.
- Рекомендации, для каких задач лучше подходит каждая настройка (Код vs Статьи vs Брейншторм).

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000`
