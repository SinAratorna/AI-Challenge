# Day 8: Работа с токенами (Экономика контекста)

Этот проект показывает, как именно расходуются токены при ведении долгого диалога с ИИ, и что происходит, когда вы упираетесь в лимиты генерации.

## Особенности Агента (TokenAwareAgent)
Агент теперь умеет "предвидеть" затраты. Перед отправкой запроса он локально использует библиотеку `tiktoken` (энкодер `cl100k_base` от OpenAI), чтобы подсчитать, сколько токенов весит:
- Текущий запрос пользователя.
- Вся сохраненная история предыдущих диалогов.
А после ответа он парсит официальный ответ от API (поле `usage`), чтобы показать, сколько токенов в итоге было потрачено и по какой причине остановилась генерация.

## Что можно увидеть в интерфейсе:
1. **Как растет цена длинного диалога:** В боковой панели вы увидите, что с каждым вашим сообщением поле *"Отправлено в API"* растет как снежный ком, так как туда пересылается вся старая переписка.
2. **Искусственное переполнение:** В UI добавлен выпадающий список для принудительного занижения `max_tokens` (до 50 или 10 токенов). Если попросить модель написать длинную сказку с лимитом в 10 токенов, она оборвется на первом предложении. Агент это отследит (получив статус `finish_reason: length`) и выведет красное предупреждение (Alert).

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000` в браузере.
