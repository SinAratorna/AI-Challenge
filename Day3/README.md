# Day 3: Разные способы рассуждения

В этом проекте реализована "Лаборатория рассуждений". Одно Web-приложение позволяет отправить одну логическую задачу на API и получить решение сразу 4 разными методами промптинга:

1. **Прямой ответ:** Стандартный запрос без хитростей.
2. **Пошаговое рассуждение (Chain of Thought):** Модели дается жесткая инструкция "решай шаг за шагом". 
3. **Мета-промптинг (2 этапа):** Бэкенд делает 2 запроса. Сначала просит ИИ создать идеальный промпт для задачи. А затем вторым запросом передает этот созданный промпт + задачу для финального решения. В UI выводятся оба этапа.
4. **Группа экспертов:** Ролевой промпт, где модель разделяется на Математика, Скептика и Судью, которые ведут диалог для поиска скрытых подвохов (как в задаче с дырявым ведром).

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000`

Модель по умолчанию: `openrouter/google/gemini-3.5-flash` (выбрана как самая доступная и быстрая для тестов).
