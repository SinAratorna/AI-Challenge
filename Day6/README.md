# Day 6: Первый агент (Инкапсуляция)

В этом проекте мы создали полноценного чат-бота, но с важным архитектурным изменением: логика работы с LLM вынесена в отдельную сущность — класс `SimpleAgent`.

## Что реализовано:
1. **Файл `agent.py`:** Содержит класс `SimpleAgent`. У него есть свое состояние (API-ключ, модель, системный промпт) и метод `process_request()`. Именно агент знает, по какому URL обращаться к API, как формировать заголовки и как парсить JSON-ответ.
2. **Файл `app.py`:** Содержит Flask-сервер и Web-интерфейс в виде классического чата. Сервер больше не дергает API напрямую. Вместо этого он создает экземпляр агента `agent = SimpleAgent(api_key)` и просит его обработать сообщение `agent.process_request(message)`.

Это основа для создания сложных агентов (которые в будущем смогут запоминать историю, вызывать функции и т.д.).

## Запуск
1. Перейдите в папку `Day6`.
2. Установите зависимости (если еще не установлены):
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите сервер:
   ```bash
   python app.py
   ```
4. Откройте `http://localhost:5000` в браузере, вставьте ключ a101 и начните общаться с агентом.
