# Day 10: Управление контекстом (Разные стратегии)

В этом проекте агент умеет использовать три абсолютно разные стратегии работы с памятью, которые можно переключать прямо в интерфейсе!

## Стратегии
1. **Sliding Window (Скользящее окно):**
   - Самый простой и дешевый метод.
   - Агент хранит и отправляет в API только последние 4 сообщения. Все, что было сказано раньше, безвозвратно теряется.

2. **Sticky Facts (Важные факты):**
   - Решает проблему "забывчивости" Sliding Window.
   - При каждом сообщении пользователя в фоне работает вторая LLM. Она анализирует текст и извлекает оттуда факты (имена, требования к проекту и т.д.) в виде JSON `{"ключ": "значение"}`.
   - Эти факты навсегда прикрепляются к Системному Промпту. Даже если окно сообщений уедет вперед, агент все равно будет помнить, как вас зовут и что вы обсуждаете.

3. **Branching (Ветки диалога):**
   - Механика как в Git. 
   - Позволяет создать чекпоинт (новую ветку), которая скопирует всю текущую историю.
   - Вы можете пойти по одному пути диалога (например, обсуждать сайт на Python), а затем в один клик переключиться на другую ветку и обсуждать сайт на Node.js, не смешивая контексты!

## Запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://localhost:5000` в браузере.
